---
description: 사용자의 개입 없이 직접 터미널 명령을 실행하여 GitHub에 커밋 및 푸시하고 Actions 배포를 트리거합니다.
---
이 명령어가 호출되면, 사용자에게 명령어를 타이핑하라고 안내하지 말고 **반드시 네가 가진 `bash` 실행 도구나 `github` MCP를 이용해 아래 명령을 직접(Directly) 실행하세요.**

1. `bash` 도구로 `git status` 및 `git diff`를 실행하여 변경 사항을 확인하세요.
2. 변경 사항을 바탕으로 적절한 커밋 메시지를 생성하세요.
3. `bash` 도구로 `git add .`를 직접 실행하세요.
4. `bash` 도구로 `git commit -m "생성한 메시지"`를 직접 실행하세요.
5. `bash` 도구로 `git push origin HEAD` (또는 현재 브랜치)를 직접 실행하세요.
*경고:* 절대 사용자에게 `! git push`를 입력하라고 텍스트로 출력하지 마세요. 모든 과정은 네가 자율적으로 툴을 호출해서 완료해야 합니다.
6. 푸시 성공 메시지가 콘솔에 반환되면, GitHub Actions 배포가 시작되었음을 사용자에게 알리고 URL을 제공하세요.
